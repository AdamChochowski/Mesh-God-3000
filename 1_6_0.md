# MeshGod3000 – Version 1.6.0  
## Community & Direction

### Summary  
This update introduces a **Community Voting section** inside Mesh God 3000.  
Its purpose is to guide future development based on **real user needs and daily workflows**, instead of guessing priorities or pushing unnecessary features.

The Community section is designed to be **informational and optional**, without interrupting normal work.

---

## 🟢 Added

### **Community Voting Panel**  
A new Community panel has been added to the editor interface.

- Displays **version-based feature proposals**
- Clearly indicates that proposals depend on the installed MeshGod version
- No popups, notifications, or forced interaction
- Provides an optional link to Discord for discussion and voting

Voting happens externally and does not affect tool functionality.

---

### **Usage-Based Community Icon**  
A Community icon has been added next to the editor controls.

- Icon appearance changes over time based on **real editor usage**
- Usage is counted **once per day**
- No analytics, tracking, or network communication
- Visual only (no messages, no achievements)

This serves as a quiet indicator of long-term use, not gamification.

---

## 🟡 Changed

### **Development Workflow**  
Future MeshGod development will be more directly influenced by community feedback.

- Feature priorities are guided by voting results
- Focus remains on practical mesh-editing tools
- Emphasis on stability and daily usability

No major mesh operations were added in this update by design.
