# MeshGod3000 – Version 1.7.0  
## Skinned Mesh & Flip Normals

### Summary  
This update adds **experimental Skinned Mesh Renderer support**, allowing most MeshGod3000 mesh operations to work directly on skinned meshes with bone rigs.  
While still marked experimental, the system is stable and fully usable in real workflows.

Based on **community voting**, this version also introduces **Flip Face Normals**, making it easy to fix incorrectly oriented faces.  
Several minor fixes improve undo behavior for core mesh operations.

---

## 🟢 Added

### **Experimental Skinned Mesh Renderer Support**  
MeshGod3000 now supports editing **Skinned Mesh Renderers**.

The following tools are now available for skinned meshes:
- Mesh Move  
- Mesh Scale  
- Mesh Rotate  
- Mesh Delete  
- Separate Selection  
- Separate by Loose Parts  
- Smooth Shading  
- Flat Shading  
- Save as FBX  
- Save as Mesh  
- Rebind to existing bone rig after mesh changes  

This brings skinned meshes closer to the same editing freedom as static meshes.

---

### **Flip Face Normals**  
A new operation allowing users to flip normals on **selected faces**.

- Fixes inverted or wrongly oriented polygons
- Useful for imported or procedurally generated meshes
- Requested and voted by the community

---

## 🟡 Changed / Fixed

### **Undo Improvements**  
Undo operations have been fixed and improved for:
- Mesh Move  
- Mesh Scale  
- Mesh Rotate  

These changes improve reliability during iterative editing, especially on skinned meshes.
