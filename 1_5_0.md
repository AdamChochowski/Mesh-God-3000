# MeshGod3000 – Version 1.5.0  
## Shading Operations

### Summary  
This update introduces two new shading operations that allow artists to apply **smooth** or **flat** shading to *only the selected region of the mesh*.  
The rest of the mesh stays untouched, enabling precise, non-destructive control over lighting and shading transitions.

These tools are designed for fixing artifacts, controlling visual style, and preparing assets for real-time rendering workflows.

---

## 🟢 Added

### **Shadow Smooth**  
Applies smooth shading **only to the selected triangles**.  
Vertices in the selected region that occupy the same position (and UV) are merged and share averaged normals.  
This produces seamless, soft shading transitions.

- Affects selected area only  
- Leaves all other triangles and vertices unchanged  
- Supports Undo  
- Ideal for repairing shading seams or smoothing sculpted regions

---

### **Shadow Flat**  
Applies flat shading **only to the selected triangles**.  
Every selected face receives its own set of duplicated vertices so the normals become perfectly flat.

- Only selected triangles become flat shaded  
- Rest of the mesh remains untouched  
- No smoothing across triangle borders  
- Supports Undo

Perfect for hard-surface modeling, stylized looks, and fixing shading glitches.

## 🟡 Changed

### **Updated Tooltip – Remove Unused Materials**  
The tooltip text was rewritten for clarity.  
The tool now clearly states that it:

- Scans all submeshes  
- Removes materials unused by any geometry  
- Reduces draw calls and unnecessary shadow casters  
- Improves runtime performance
