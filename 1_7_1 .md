# MeshGod3000 – Version 1.7.1  
## macOS Hotfix

### Summary  
This is a **small macOS-only hotfix** that resolves an internal editor error related to native mouse position tracking.  
No new features or workflow changes were introduced in this update.

---

## 🟡 Fixed

- **macOS Editor Stability** – Fixed an issue in native mouse position tracking caused by an invalid CoreGraphics struct definition.  
  The fix ensures correct memory layout for native interop and prevents potential editor errors or undefined behavior on macOS systems.
